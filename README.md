## Project Description

This project simulates a city road network using graphs and Dijkstra's algorithm.
The program loads a city map from a text file, calculates shortest paths between cities, and displays the network graphically using Raylib.

## Background

The goal of the project is to demonstrate the use of graph data structures, shortest path algorithms, file handling, and graphical visualization in C.
